MMSLT Region-Masking Ablation — 4,000-sentence training set

Ver. 1

All models on this page are trained on the same 4,000-sentence-pair How2Sign split (random4000_v3) — a deliberately small-scale slice, not the full ~31K-sentence How2Sign training set. Scaled-up training runs (10K / 20K / ~31K sentence pairs) are planned as a follow-up, to test whether grounding quality actually improves alongside BLEU as training data grows, or whether BLEU gains come from a direction that doesn't correspond to looking at the signer more correctly.

Cross-check against an independent grounding signal

For each region, does MMSLT's own sensitivity to masking it line up with an independent, CLIP/SigLIP-derived signal (which region a CLIP/SigLIP scorer thought best matched a cue word in that sentence)? Compares median Δ BLEU on sentences where that signal flagged this region as best vs. sentences where it didn't (Mann-Whitney U, BH-adjusted).

None of the 8 comparisons reach significance (all q ≥ 0.95) — MMSLT's region-sensitivity (above) doesn't track this particular word-level grounding signal. That's consistent with the grounding pipeline's own internal finding that CLIP/SigLIP raw scores don't reliably separate real vs. noise grounding across regions; it isn't evidence against the masking-ablation result itself. shoulder has 0 flagged sentences because it wasn't one of the categories that earlier grounding pass scored.

Does it matter more on sentences that need non-manual grammar?

Sign-linguistics theory says face/eyes/mouth/shoulder carry grammatical non-manual markers (NMM) for things like negation, conditionals, hedging, intensifiers, and rhetorical wh-cleft constructions. GT here is the English translation (not an ASL gloss), so each flag below is a text-based proxy for "this sentence likely needed that non-manual marker" — not a guarantee. Bars compare mean ΔBLEU on flagged vs. not-flagged sentences (Mann-Whitney U), for each of the 5 non-manual regions.

None of the 75 tests (5 regions × 3 metrics × 5 flags) survive FDR correction — with n≈300 split into these subgroups, this is underpowered, not a clean null. The two closest raw signals (both q≈0.066, just short of 0.05): masking mouth hurts chrF far more on hedging sentences (Δ=-2.14 vs +0.10) — plausible, since ASL hedging has distinctive mouth morphemes — and masking face hurts semantic similarity more on rhetorical wh-cleft sentences (Δ=-0.066 vs -0.002). Worth re-testing with a larger sample rather than treating as confirmed. Also: only 2 of 300 sentences are genuine questions in this how-to-narration test set, so the question/NMM hypothesis specifically can't be tested here at all — see the write-up for why "what/when/where..." sentences were reclassified as rhetorical-cleft rather than questions.

Cross-attention: is the decoder actually looking anywhere specific?

mBART's decoder cross-attends to the visual encoder sequence (17 time-positions after TemporalConv's ~4× downsampling, each ≈4 original frames) at every generated word. Extracted from the last decoder layer, averaged over its 16 heads, from a teacher-forced re-pass of the model's own generated sentence through best_checkpoint.pth — so this is exactly what happened during that generation, not a hypothetical. Frame-index mapping was derived from the model's exact padding/downsampling arithmetic and verified against a real sample (orig_len=64 → video_length=80 → encoder length=17) before use.

MMSLT vs. SpaMo vs. VTaMo vs. CNNMamba

Same test set, five architectures

SpaMo, VTaMo, and CNNMamba all run the identical How2Sign random4000_v3 split and the same 300 test sentences as MMSLT (corrected 2026-09-11 — SpaMo's test set was originally prepared from an earlier, 259-sentence version of the grounding-sampling CSV; it has since been regenerated from the same canonical 300-sentence CSV MMSLT uses, so all four are now scored on an identical set). SpaMo pairs frozen CLIP-ViT + VideoMAE features with a LoRA-tuned Flan-T5; VTaMo pairs the same frozen CLIP-ViT features (no VideoMAE — spatial-only fusion) with its own LoRA-tuned Flan-T5, but downsamples them with a learnable attention-pooling stack instead of SpaMo's fixed conv+maxpool, and adds explicit multi-granularity vision-text alignment losses during training. CNNMamba pairs a ResNet18 CNN visual encoder — trained end-to-end on raw RGB frames, not frozen like SpaMo/VTaMo's CLIP-ViT — with a single unidirectional Mamba layer (matching the released Event-CSL/OpenESL code this model reproduces, rather than that paper's more elaborate prose description) and then the same TemporalConv conv/pool stack SpaMo and VTaMo already use; all three non-MMSLT models share the identical Flan-T5 + LoRA decoder, kept deliberately constant so only the visual encoder / temporal module varies across the comparison. Because it sees raw pixels rather than precomputed features, CNNMamba can mask regions inline exactly like MMSLT does — SpaMo and VTaMo, by contrast, can't mask pixels inline at all: both only ever see precomputed CLIP-ViT features, so VTaMo directly reuses the same masked feature files SpaMo's offline re-extraction already produces (identical masking, zero extra extraction work). Same landmark cache logic, same 8 regions, same metrics, across all four.

A fifth model, WiCV2023 (fairseq sign2text_transformer, WACV2023 "Sign Language Translation from Instructional Videos") ran the identical How2Sign random4000_v3 split and appears in the overview tiles above (298 of 300 test sentences scored — 2 excluded for missing precomputed I3D features) — its Test BLEU-4 row is the same sacrebleu corpus computation as the other four, so it's directly comparable; its Dev BLEU-4 at that epoch row (marked †) is fairseq's own tracked validation metric, reduced_sacrebleu, not the same computation as the other models' dev BLEU-4, so don't compare that one row across models. WiCV2023 IS excluded, however, from this card's region-masking chart and the three that follow (effect-of-masking chart, region-agreement/crossval, effect-size heatmap) — it trains on precomputed I3D features only, never sees raw video pixels, and the original I3D feature extractor isn't available in this workspace to re-extract features with regions masked (a private, unreleased pipeline — see project notes). This is a deliberate scope decision, not an oversight: WiCV2023 reappears further below, in the Temporal Attention Map and GradCAM sections, which need only the model's own attention weights, not region-masked re-inference.

Do the two models agree on which regions matter?

Friedman test: do the 8 regions' deltas differ from each other at all, within each model? All three say yes, decisively — but that's a different question from whether any single region survives correction (chart above), or whether the pattern matches an independent grounding signal (table below).

Cross-check against the independent grounding signal

Same CLIP/SigLIP-derived best_region labels used above, now compared side by side. None of the four models' masking-sensitivity lines up with this word-level signal for any region.

Reading the four models together: MMSLT (BLEU-4 1.58, well past convergence at epoch 11) shows FDR-significant BLEU deltas for 5 of 8 regions, all in the expected "masking hurts" direction. SpaMo (BLEU-4 1.08, early-stopped at epoch 39/500 on the same 4,000 training sentences) shows FDR-significant BLEU deltas for only 1 of 8 regions (body) — but chrF, a more sensitive string metric, finds a significant, consistently negative effect for 7 of 8 regions (all but shoulder). Semantic similarity shows no significant effect for any region — on an earlier, incomplete 259-sentence version of this test set, semantic similarity had shown a significant positive effect for several regions, which this write-up flagged at the time as a likely artifact of SpaMo's repetitive outputs rather than real grounding; that anomaly disappeared once the test-set mismatch with MMSLT was corrected, which is itself a useful data point about not over-reading small-sample subgroup effects.

VTaMo (BLEU-4 24.63 — an order of magnitude past either of the other two, EarlyStopping-converged at epoch 141/500 on the same 4,000 training sentences) is the cleanest region-masking result in the project: eyes, body, and face ALL survive FDR correction on BLEU (q=3.3×10⁻⁵, 2.8×10⁻³, 3.6×10⁻³), and chrF confirms the same three plus nose (4 of 8 regions). Every region's mean delta is negative — unlike MMSLT and SpaMo, where a couple of regions had slightly positive mean deltas — so masking never helps VTaMo, only hurts to varying degrees. This is the only one of the four models whose region-masking evidence is unambiguous by the FDR-corrected test itself, rather than needing a softer metric (chrF) to find any signal at all.

CNNMamba (BLEU-4 1.40, best val/bleu4 at epoch 31, EarlyStopping-stopped at epoch 131) lands closest to MMSLT's mixed picture: only 1 of 8 regions (body) survives FDR correction on BLEU, but chrF finds 3 of 8 (body, shoulder, eyes) and — the strongest semantic-similarity signal of the four models — simscore finds 3 of 8 as well (mouth, face, shoulder), though all three of those simscore hits run in the masking-improves-similarity direction, the same paradoxical pattern flagged above as a likely artifact for SpaMo's earlier, since-corrected test set — treat that specific result with the same skepticism, not as real evidence masking helps. CNNMamba's region ranking overlaps meaningfully with MMSLT's: body is the single most disruptive region to mask for both models, and shoulder is a significant chrF hit for both too — a plausible convergent signal from being the two models (of the four) that see raw pixels rather than precomputed CLIP-ViT features.

All four models agree that which region is masked matters (Friedman, p≪.01 across the board) and that none of them tie cleanly to the independent CLIP/SigLIP grounding labels (table above) — so a well-trained model (MMSLT), a barely-trained one (SpaMo), a properly-converged one (VTaMo), and a first CNN-based one (CNNMamba) on the same small dataset all land on "some regions clearly matter, but not obviously the linguistically 'correct' ones," even though they disagree sharply on how many regions clear the statistical bar.

Temporal Attention Map: where does the decoder actually look?

A second, independent grounding check, orthogonal to region-masking: teacher-force each model's own generated sentence back through it with output_attentions=True and take the last decoder layer's cross-attention (averaged over heads) over the visual encoder positions, mapped back to original video frames. Peakiness = 1 − normalized entropy of that attention (0 = spread uniformly over every frame, 1 = fixed on a single frame). If a model is really grounding its words in specific moments, sentences with peakier attention should also be the ones that region-masking hurts more — that's the scatter below.

MMSLT: peakiness correlates with masking sensitivity (Spearman r=+0.34, p=2×10⁻⁹) — sentences the decoder looks at sharply are the same ones masking a region actually hurts. A real, independent confirmation of the region-masking result above. SpaMo: no such relationship (r=−0.09, p=0.11, wrong-signed if anything) — attention sharpness and masking sensitivity are unrelated. VTaMo: also no relationship (r=−0.09, p=0.14) — despite having by far the cleanest region-masking result of the three, its raw decoder attention doesn't independently confirm it. Worth a caveat here: VTaMo's attention shows a strong "sink" pattern — the single highest-weight position is almost always the very first visual token (mean peak position 0.008, essentially frame zero, versus MMSLT's 0.35 and SpaMo's 0.45) regardless of which word is being generated — a well-documented transformer artifact, not a mapping bug (verified directly against the model's raw attention weights). That sink likely swamps whatever real signal TAM's peakiness metric might otherwise carry for this model. CNNMamba: no relationship either (r=+0.02, p=0.70) — the weakest correlation of any model here in either direction, essentially flat. Its mean peak position (0.459) sits centrally, with none of VTaMo's boundary-sink pattern, so this null isn't explained away by an attention artifact the way VTaMo's plausibly is — for CNNMamba it looks like a genuinely clean null. WiCV2023: mean attention entropy 0.942 (peakiness ≈0.058 — the least peaked of the five, though this is fairseq's own encoder-decoder cross-attention, not mBART's, so not directly comparable in scale), mean peak position 0.425. No peakiness-vs-masking-sensitivity correlation exists for WiCV2023 — it has no region-masking ablation to correlate against (see note above). Five models, five different pictures for this one method: convergent for MMSLT, null for SpaMo, VTaMo, and CNNMamba alike (for probably different underlying reasons — see the sink-pattern caveat above for VTaMo specifically), and simply not testable for WiCV2023.

GradCAM: does gradient pressure agree with raw attention?

A third, transformer-adapted method (attention × gradient, the standard single-layer simplification of Chefer et al.'s relevance propagation): same teacher-forced setup as TAM, but this time backpropagating the generation loss to that same cross-attention tensor first — GradCAM = ReLU(attention × d(loss)/d(attention)), averaged over heads. Where TAM asks "where is the decoder looking," this asks "where would more attention have actually helped." First panel: does GradCAM peakiness predict masking sensitivity, same as the TAM chart above. Second panel: do TAM and GradCAM even agree with each other, sentence for sentence?

Do TAM and GradCAM agree on which sentences are "peaked"?

SpaMo: the two methods mostly agree (r=+0.74, p≈10⁻⁵³) and neither predicts masking sensitivity — a consistent, if grounding-negative, picture. Its raw per-token peak positions show a partial version of VTaMo's sink below: across all generated tokens, ~17% (TAM) / ~30% (GradCAM) peak at the very first encoder position and ~33% (TAM) / ~24% (GradCAM) at the very last — roughly half of all tokens' attention lands on one of the two sequence boundaries regardless of sentence content, split between the start of the CLIP-ViT segment and the end of the VideoMAE segment rather than concentrated at one point like VTaMo's. Re-running the peakiness-vs-maskability correlation with those two boundary positions excluded from the entropy calculation does not recover a positive, grounding-consistent relationship (TAM: r=−0.09→−0.12, nominally p=.03 but wrong-signed; GradCAM: r=−0.06→−0.08, still n.s.) — so the sink isn't masking a real signal underneath, it's just one visible symptom of attention that never developed genuine content-dependent structure in the first place, consistent with SpaMo's own frozen (never fine-tuned) CLIP-ViT/VideoMAE visual backbone. CNNMamba: TAM and GradCAM agree reasonably strongly (r=+0.66, p≈4×10⁻³⁸) — closer to SpaMo's near-total agreement than to VTaMo's weak r=+0.17 below — but GradCAM peakiness still doesn't predict masking sensitivity (r=+0.08, p=0.16), the same qualitative null every model shows on this specific check. Its raw peak positions sit centrally (mean 0.44 for GradCAM, 0.46 for TAM), with no VTaMo-style attention-sink pattern, so unlike VTaMo this null isn't explained away by a boundary artifact — gradient pressure and raw attention agree with each other about where CNNMamba is looking, they just don't agree with the region-masking evidence about what actually matters. VTaMo: TAM and GradCAM agree too, though more weakly (r=+0.17, p=0.003) — same direction as SpaMo, not the flat r≈0 you'd get from two unrelated signals, but nowhere near SpaMo's near-total agreement. GradCAM peakiness itself still doesn't predict masking sensitivity (r=+0.06, p=0.33, same null result as TAM above) — and GradCAM's own peak positions are spread much more evenly across the clip (mean peak position 0.37) than TAM's sink-dominated 0.008, consistent with the gradient term breaking the attention-sink pattern rather than confirming it points somewhere meaningful. MMSLT: GradCAM peakiness is significantly negatively correlated with masking sensitivity (r=−0.30, p≈10⁻⁷) — the opposite sign from TAM's own +0.34 above — and TAM/GradCAM disagree on which sentences are peaked almost as strongly as two measurements of the same thing can (r=−0.93). We do not have a confirmed causal story for this inversion (one candidate: GradCAM may be picking out sentences the model is already confident about — short, generic, "safe" outputs — which could plausibly be both gradient-peaked and masking-insensitive, while raw attention peaks on genuinely salient moments; this is speculative, not verified here). Read this as the honest result, not a resolved one: for MMSLT, which interpretability method you trust changes the conclusion — a caution against treating any single attention-based method, including the region-masking result itself, as settled proof of grounding. VTaMo is the sharpest illustration of that caution taken the other way: its region-masking evidence is the strongest of the three models, yet neither attention-based method here independently confirms it — a reminder that a clean causal ablation and a clean attention story are genuinely separate kinds of evidence, and a model can have one without the other. WiCV2023: mean GradCAM entropy 0.864 (peakiness ≈0.136), mean peak position 0.439. TAM and GradCAM agree strongly here too (r=+0.77, p=7.2×10⁻⁵⁹) — comparable to SpaMo's near-total agreement (r=+0.74) and well above VTaMo's weaker r=+0.17 — but as with TAM above, GradCAM peakiness can't be checked against masking sensitivity for this model, since it has none to check against.

Grounding Precision: does spatial attention actually land where it should?

A fourth check — this time spatial rather than temporal: what fraction of the model's spatial GradCAM / gradient-saliency mass falls inside a candidate "correct" body region's landmark-derived bounding box? Two independent choices of "correct," computed and compared side by side: external (the CLIP/SigLIP-derived grounding_best_region label used in the crossval tables above — model-independent) and internal (this model's own most masking-sensitive region for that exact sentence — a self-referential "does it look where it itself claims to care" check). Each is compared against a chance baseline: the region's own bounding-box area as a fraction of the frame — a model with no real localization at all would land right on that baseline; genuine grounding would land above it.

Mean attention share landing in the "correct" region (●) vs. that region's own area-fraction baseline (○) — bar shows the gap between them.

SHAP: exact Shapley values across all 8 regions jointly

A fifth check, addressing a real limitation of the region-masking ablation above: that method only ever masks one region at a time, holding every other region unmasked — so it can't see whether regions substitute for each other (e.g. if masking both hands together hurts less than masking either alone, because the model falls back on the other) or compound (hurts more together than the sum of each alone). Exact Shapley values fix this by construction: for each of the 8 regions, φ is the average marginal drop in a metric from additionally masking that region, averaged over all 2⁸⁻¹=128 possible "what else is already masked" contexts, weighted by the standard Shapley combinatorial weights — computed here from all 2⁸=256 masked-region-subset combinations per model (not a Monte Carlo approximation). This is far more expensive than single-region masking (256 re-inference passes per sentence instead of 8), so it's restricted to a fixed 60-sentence subsample of the 300-sentence test set (seed=42, results/sampling/shap_sentence_subsample_60.json, identical subsample across all models) rather than the full set — treat magnitudes as noisier than the 300-sentence results above, and cross-metric/cross-model agreement as the more trustworthy signal than any single p-value. Computed here for MMSLT, SpaMo, and VTaMo; CNNMamba's SHAP run was still in progress at the time of this update and will be added in a follow-up using the same subsample.

Scorers & methodology

Models, checkpoints & test set

How2Sign random4000_v3 split, 300-sentence test set (298/300 for WiCV2023). Checkpoints: MMSLT best_checkpoint.pth (epoch 11); SpaMo epoch 39/500 (early-stopped); VTaMo epoch 141/500 (EarlyStopping-converged); CNNMamba epoch 31 best, EarlyStopping-stopped epoch 131; WiCV2023 fairseq sign2text_transformer (excluded from region-masking — I3D-only, can't mask pixels).

Text-overlap scorers

BLEU / chrF
sentence-level, computed via sacrebleu.
Semantic similarity
cosine similarity, all-MiniLM-L6-v2 sentence embeddings.

Region-masking method

8 body regions blacked out via MediaPipe Holistic landmarks; same checkpoint re-runs generation; Δ vs. unmasked baseline. Paired Wilcoxon signed-rank test per region×metric, BH-FDR corrected across 8 regions × 3 metrics. Friedman test checks whether regions differ from each other at all.

Independent grounding cross-check

CLIP/SigLIP-derived grounding_best_region label per sentence (model-independent) — Mann-Whitney U vs. each model's own region-masking sensitivity, BH-FDR corrected.

Attention-based scorer

Same TAM (raw cross-attention) / GradCAM (attention×gradient) pair as the companion Grounding Example Viewer artifact — peakiness (1 − normalized entropy) correlated against masking sensitivity (Spearman r).

Grounding Precision

Fraction of spatial GradCAM/saliency mass landing inside a candidate "correct" region's landmark bounding box, vs. that region's own area-fraction chance baseline. Two label sources compared: external (CLIP/SigLIP) and internal (each model's own most masking-sensitive region).

SHAP

Exact Shapley values (all 2⁸=256 masked-region-subset combinations, not Monte Carlo), computed over a fixed 60-sentence subsample (seed 42) shared across models. BH-FDR corrected across each model's own 8 regions.

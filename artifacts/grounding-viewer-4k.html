Scorers & methodology

Models & test set

MMSLT, SpaMo, VTaMo, WiCV2023, CNNMamba — all trained on the same How2Sign random4000_v3 split (4,000 training sentence pairs) and evaluated on the same 300-sentence test set (298/300 for VTaMo and WiCV2023, each missing 2 sentences for model-specific reasons — see footer).

Temporal grounding scorer

TAM
raw decoder cross-attention, last layer, averaged over all attention heads.
GradCAM
ReLU(attention × ∂loss/∂attention) — the standard attention×gradient relevance approximation, same layer/heads as TAM.

Spatial grounding scorer

GradCAM only. Classic Grad-CAM on the trained ResNet18's last conv layer (MMSLT, CNNMamba); gradient-based saliency on CLIP-ViT pixel input (SpaMo, VTaMo). Not available for WiCV2023 (trains on precomputed I3D features, never sees raw pixels).

Sidebar match color

Semantic similarity — cosine similarity between prediction and ground truth using all-MiniLM-L6-v2 sentence embeddings, on the unmasked/original condition. A rough at-a-glance correctness signal, not a BLEU/chrF substitute.

Per-word view

MMSLT/SpaMo/VTaMo only. Each word's own temporal window = the contiguous run of encoder positions ≥50% of that word's attention peak ("full width at half maximum"), mapped to original video frames.
